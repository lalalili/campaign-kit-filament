# Changelog

All notable changes to `lalalili/campaign-kit-filament` are documented in this file.

## [0.1.3] - 2026-07-05

### Changed

- 更新 README，將 Filament 支援版本標示為 `^4.0 || ^5.0`，與 `composer.json` 一致。

### Internal

- 新增 CI / release workflow，並補上 larastan 靜態分析設定。

## [0.1.2] - 2026-05-05

### Added

- Support for Filament v4 and v5.

## [0.1.1] - 2026-03-02

### Changed

- Removed Composer fixed `version` field (versioning is tag-driven).

## [0.1.0] - 2026-03-01

### Added

- Initial release: Filament form preview component for `lalalili/campaign-kit` layouts, with a publishable preview Blade view. Depends on `lalalili/campaign-kit`.
